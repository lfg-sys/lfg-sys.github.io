Soldat (meaning "soldier" in Italian, German, Russian, Norwegian, Danish, Swedish, French, Catalan and Romanian) is a Polish 2D multiplayer game for Windows. It is a side-scroller inspired by Liero and Scorched Earth, combined with elements from Counter-Strike and Worms. The game is shareware.
