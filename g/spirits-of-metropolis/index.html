Spirits of Metropolis

Vertigo Gaming Inc. · 2009

Build several chains in one turn, then choose when to set them off.

A puzzle game with a twist on combos. When you make a chain, the level does not react straight away; you decide when the chains go off, so you can line up several in a single turn.
